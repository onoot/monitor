# magiclib - сайт Магической школы с основной информацией для учеников

## Технологический стек

- Site: python + psycopg2 + Flask
- База данных: PostgreSQL

## Описание функционала

- Регистрация/Авторизация
- Просмотр студентов, списка литературы

## Уязвимости и исправления

### Уязвимость 1: Открытая база данных

Проблема: Есть открытая база данных, которую не посещает даже чекер

Исправление: Закрыть ее, йоу

### Уязвимость 2: закодированный пароль (флаг) спрятан на странице со всеми пользователями

Проблема: Если выделить текст на странице students, можно обнаружить закодированные флаги

Исправление: Использовать собственные методы кодировки

### Уязвимость 3: Авторизация не проверяет пароль

Проблема: При авторизации нет проверки пароля

Исправление: Добавить проверку пароля

### Уязвимость 4: Нет обработки пользователей в базе данных

Проблема: База данных не удаляет пользователей и не выставляет верхнего ограничения на количесво выделяемой памяти на пользователя

Исправление: Добавить это

# Curs - сервис для участия в лотерее

## Технологический стек

- **Site**: Golang + Gin
- **База данных**: MySQL

## Описание функционала

- Регистрация/Авторизация
- Просмотр выданного лотерейного билета
- Список пользователей (для админа)

## Уязвимости и исправления

### Уязвимость 1: Несанкционированный доступ к флагам

**Проблема**: Все флаги можно просмотреть во вкладке `/` под учетной записью администратора. Поскольку запрос на авторизацию не экранируется, возможен доступ через SQL-инъекцию.

**Исправление**: Удалить данные флагов из фронтенда/экранировать запрос

### Уязвимость 2: Открытый доступ к базе данных

**Проблема**: База данных доступна по отдельному порту

**Исправление**: Сменить аутентификационные данные в базе

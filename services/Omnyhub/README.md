# Omnyhub

Полноценное веб-приложение с фронтендом на React и бэкендом на Node.js.

## Структура проекта

- **front/** - фронтенд на React
- **backend/** - бэкенд на Node.js и Express

## Настройка и запуск

### Бэкенд

1. Перейдите в папку backend:
```bash
cd backend
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите сервер:
```bash
npm run dev
```

Бэкенд будет доступен по адресу: http://localhost:4444

### Фронтенд

1. Перейдите в папку front:
```bash
cd front
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите приложение:
```bash
npm run dev
```

Фронтенд будет доступен по адресу, который покажет Vite (обычно http://localhost:5173).

## Функционал

- Регистрация пользователей
- Авторизация
- Аутентификация с использованием JWT
- Защищенные маршруты

## Требования

- Node.js версии 14.x или выше
- MongoDB (установленный и запущенный локально или удаленный)

## API Endpoints

### Регистрация
- **POST /register**
  - Тело запроса: `{ username, email, password }`

### Авторизация
- **POST /auth**
  - Тело запроса: `{ username, password }`

### Получение данных пользователя
- **GET /auth/me**
  - Заголовки: `Authorization: Bearer YOUR_TOKEN`
